# X 推广 ROI 接入设计（商城订单后台）

> 用户 2026-10-18 18:26（北京时间）主动给出订单后台：https://lumaozhanghao.com/user/shop/order
> 这是 X 业务（chuhai.wiki 卡密商城）的后台。已向用户提出把订单数据并入 X 日报，登录方式待用户确认。

## 目标

X 日报现在只看发帖/涨粉/点赞——都是虚荣指标。接上订单数据后，每日汇报变成：**今天两条帖子带来了多少单、多少 GMV**，这才是 X 推广真正的 ROI。

## 需要用户给的

- 后台登录权限。账号密码不经过聊天——发安全登录入口，用户自己在浏览器里登，我只拿授权会话。
- 确认要拉的口径：按下单时间算，还是按支付时间算。

## 每天要拉的字段（示例）

- 当日订单数、GMV、客单价、新客数
- 商品结构：Gmail老号 / AI会员 / 成品号 / eSIM / 接码 / FB/TK/INS / Apple ID 各多少单
- 异常：退款/取消单（防止刷单或误操作污染数据）

## 归因缺口（需要用户拍板）

光有订单数，还不知道**哪条帖子带来的**。两个方案：

- **方案A（轻）**：bio 链接 chuhai.wiki 加 UTM 参数（如 `?utm_source=x&utm_campaign=acct2-p2`），每周换一次，按周归因。实现成本最低。
- **方案B（准）**：每条推广帖配专属优惠码，订单按优惠码归因到帖。最准，但要改商城配置。

建议先 A 跑起来，看到效果再决定要不要 B。
