# 李峰口播出镜精剪

把一条医生口播剪成可直接交审的竖版成片。参考样例是 LF-20261031-04 v3.0（`/workspace/dr-lifeng-ip/cuts/LF-20261031-04/`），下次换新口播和素材时按同一套步骤重跑，不要照搬那一条的时码。

受众是 35 岁以上的国际客户：字体要看起来高端，英文字幕偏大，顶部标题突出，不要废镜头。

## 确d线

- 老板交来的素材按可发布标准使用：不质疑真实性、数字或数字人授权。数字人口播可以用，第一人称也可以。
- 不改医学事实和技术描述，MG 只呈现台词里已有的信息，不编造服务、数字或效果承诺。
- 不重塑医生的脸、身体和声音，不重新对口型。以口播原声为唯一准绳。
- 不生成假患者、假手术过程、假术前术后对比。
- 未经老板批准不得发布、不得改账号。

## 1. 收料核对

四样齐了再开工：

1. 口播原片（真人或数字人）
2. 定稿台词（英文加中文参考）
3. 实拍（接机、豪车、面诊、资质、护理、握手等）
4. 品牌素材（Logo 原文件）

缺关键镜头就先列清单要，说明每个空位缺什么。不用生成的人物画面顶替真实服务镜头。

每个素材先用 `ffprobe` 看清分辨率、时长、帧率、像素比和是否 HDR，再抽帧核对画面内容。上传顺序不等于画面顺序。iPhone HLG / HDR 先转成 SDR（`zscale` + `hable`）再调色，否则发白发灰。

## 2. 口播节奏与分镜结构

先按台词做一张密度规划表：每段几秒说什么、用什么画面撑。连续纯口播不要超过约 8 秒；重点信息（承诺、数字、流程节点、天数）一句配一个视觉支撑。目标是每 3–5 秒有新信息点。

结构按这七段排，台词没覆盖的段可以缩短但不要偷换顺序：

1. **欢迎**：接机、拥抱、走廊道，让人看到到了上海
2. **医生出镜**：口播自我介绍 + 姓名条（Dr. Li Feng / 李峰医生）
3. **资质**：证书、学会、区间环境
4. **来沪行程**：接机 → 专车接送 → 酒店 / 入住。有豪车素材就用豪车，画面要对上旁白
5. **面诊**：面部评估、翻译沟通、走进诊室
6. **手术与恢复**：手术说明、住院天数、术后随访节点
7. **CTA**：握手或欢送 + 主页链接 / WhatsApp 引导 + 品牌收尾

前 3 秒用原台词里的问题做顶部标题，不编造医生没说过的话。

同一位患者不要反复刷脸；具体出镜次数以当次任务说明为准。

## 3. 实拍匹配

- 有对应实拍：全屏竖幅重构。原素材等比放大到满高或满幅，从中截 9:16，取景跟主体。禁止信箱条加上下虚化带。
- 没有对应实拍：留口播原片，加打磨过的 MG（行程轴、清单、天数、地点），不要生硬填废镜头。
- 画面要对上旁白。旁白说「专车接送」就用车，不用机场行李顶替。
- 数字人白大褂与真人白大褂不直接接刀。
- 稍微推近（约 1.00 到 1.04）可以用在稳定镜头上，不要把关键字样、脸或 Logo 推出画外。
- 同一条口播全片用统一色调。
- 实拍自带音频要静音，用口播混音轨作为唯一声音源，保证对口型。

## 4. 字幕与包装

画布固定 1080×1920。品牌金为 `#E8C07D`（ASS `&H7DC0E8&`）。

字体（项目字体文件在 `/home/box/.fonts/`）：

- 英文标题、姓名：LF Playfair Bold / SemiBold
- 英文正文、字幕：LF Inter SemiBold / Medium
- 中文：Noto Serif CJK SC（标题）、Noto Sans CJK SC（字幕和注解）

### 顶部标题

全片针上。英文两行、Playfair 约 96 号、居中偏上（例如 `\an8\pos(540,64)`）；中文一行用品牌金、约 52 号。标题来自台词里的问题。

### 双语字幕

- 英文为主：Inter SemiBold 约 66 号，最多两行，单行宽度约 940px
- 中文为辅：Noto Sans CJK 约 44 号、浅灰色
- 按自然短句断句，不逐词闪跳；相邻字幕至少隔 0.03 秒
- 关键词（医生名、项目名、角色、核心承诺）用品牌金
- 放在画面下部安全区，躲脸、手势和 Instagram 底部按钮。参考字幕顶部约在 y=1677，白字加轻描边阴影，不用大色块底

### 姓名条

- 医生第一次出镜：`Dr. Li Feng  李峰医生`，下方金色副标题 `Alpha V Facelift · Shanghai`
- 接待（Kim）第一次出镜用完整标签：姓名约 68px；英文职务至少 34px，可以折两行（`International Patient` / `Coordinator & Interpreter`）；中文一行至少 32px（`国际客户接待 · 专属翻译`）。半透明深色底板 + 顶部金细线
- 后续单独出镜可再出约 2.5 秒短标签（姓名 + 英文职务）
- 底板下沿距字幕顶部至少 40px，不要挡脸和手。Logo 不要贴在比划的手上

### 行程 MG

五个节点与台词一致时使用：Arrival 抵达 / Consultation 面诊 / Surgery 手术 / 2–3 days inpatient 住院 2–3 天 / Aftercare 术后跟进。

- 数字人镜头放上部安全区（参考 y≈480，在标题带和人头之间）
- 实拍镜头放下部躯干区（参考 y≈1330），躲开脸和手
- 当前节点用金色加亮，已过节点依次点亮
- 术后随访可用 Week 1 / Week 2 / Month 1 / Month 3 / Month 6

### 数字人标识

数字人出镜时加顶部细条：`AI-generated presenter · 数字人讲解`。片尾可改为 `AI-generated presenter voice · Real clinic footage`。

### 片尾品牌卡

最后约 1.5–2.5 秒：背景渐变模糊加约 40% 压暗，圆形 Logo（切掉白底）约 420px 居中淡入。标题、字幕和 `Link in bio · WhatsApp` 保持清晰。不加常驻水印，不要让 Logo 漂在人之间像道具。Logo 若有白底，先做圆形透明底再贴。

## 5. 制作流水线

参考实现在成片目录的 `build_v*` 里，下一条口播复制这套脚本后改分镜表与字幕，不要从零拼装。

1. `shots.py`：分镜表。每条是成片时段、类型（`B` 实拍 / `D` 数字人）、素材、入点、速度、裁切窗、推近、锚点
2. `build_shots.py`：渲每一镜。链尾必须 `format=yuv420p,setsar=1`（`zoompan` 和缩放会改像素比，不加就会压扁）
3. `shift.py`：需要让关键画面躲字幕时再平移
4. `make_ass25.py` / `subs_core.py`：生成标题、字幕、姓名条、行程 MG、AI 标识、CTA
5. `render.sh`：拼接画面 + 轮廓渐变带 + 字幕 + 混音 + 片尾 Logo，`libx264` crf 16，25fps，AAC 48k / 192k，`+faststart`
6. 预览版：720×1280，crf 28，lanczos 缩放，`setsar=1`

数字人源片若是 544×960 且自带非 1:1 的 SAR，放到 1080×1920 后必须 `setsar=1`，否则成片会被压扁。

## 6. 导出规格

- 发布版：1080×1920，25fps，SAR 1:1，DAR 9:16，yuv420p，crf 16
- 预览版：720×1280，同上 SAR / DAR
- 时长和帧数与分镜表一致，音频与口播原声对齐

## 7. 交付前自检

先跑：

```bash
ffprobe -v error -select_streams v:0 -show_entries stream=width,height,sample_aspect_ratio,display_aspect_ratio,r_frame_rate,nb_frames -show_entries format=duration -of default=nw=1 <成片.mp4>
```

必须是 1080×1920、SAR `1:1`、DAR `9:16`、25fps。再抽关键帧：开头、每个姓名条和 MG 的首尾帧、转场中点、片尾品牌卡，放进 `qc/` 做联络表并真正看一遍。

看这几项：

- 有没有拉伸、变软、黑边
- 字幕、标题、姓名条是否叠在一起或挡脸
- Logo 是否漂在脸上、手上，或留下白底四角
- 画面是否对得上旁白
- 音频是否同步且完整

不合格就修好重导，不要把基本问题留给审核。

## 8. 交付

一并交这几件：

- 发布版 mp4
- 预览版 mp4（可选，方便手机查看）
- 双语 srt
- 分镜表（含改动说明和自检结果）

在聊天里发视频，告诉对方长按即可保存。逐条说清改了什么、自检发现了什么。改稿意见一次性收齐，目标 2–3 版定稿。
