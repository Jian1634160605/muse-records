# 检查清单

本文件是主文件的配套清单，不新增规则。主文件为准，清单只帮你逐项核对。

## 上线前占位符替换清单

- 把主号名换成你方主运营账号的对外名称。
- 把医生 IP 名换成你方医生 IP 的对外名称。
- 把咨询链接换成你方对外咨询链接。
- 把面诊链接换成你方面诊预约链接。
- 把静态代理换成你方命令行出口代理的配置来源。
- 把工作区路径换成你方存放台账的工作区根路径。
- 把线程台账、收集表、客资台账、去重台账、发布台账、每日表换成你方六本台账的实际路径。
- 把会话编号换成你方要操作的会话编号。
- 确认六本台账已建好，旧条目已按去重规则导入。
- 确认主号登录通道可用，实时哨兵已启用，定时任务定时与开关已核对。

## 每轮猎手检查清单

- 先看主号收件箱，有新回复就继续聊，用户自聊线程勿动。
- 重读已评论帖的回复楼层，楼主回我方评论就当天接话。
- 腿二每轮只扫一个群，合格意向先记收集表再触达。
- 发前重读去重台账，发完一条立即追加记账。
- 每轮新评论最多三条，无合适目标就简单说明。
- 出现平台受限提示就停该号并报告，不盲重试。

## 每轮私信盯守检查清单

- 先看台账，同一线程 30 分钟内已有实时接手记录就跳过。
- 先筛人再发，不合格标关闭，一条私信都不发。
- 主动发送只在对方当地约 8 时到 22 时进行，新回复立即回。
- 所有私信拆成两到四条短消息，留号漏斗第 3 条给钩子。
- 发出后立即做服务器端核验，未核验不得说已发送。
- 没有任何新动态就安静结束，不发报告。

## 工具速查

- 线程列表用 `threads` 加搜索对方姓名。
- 消息读取用 `messages` 加会话编号。
- 直发用 `send` 加会话编号与消息内容。
- 刷新用 `sync`。
- 定时任务用 `cron.view` 读正文，用 `cron.update` 保存完整修订版，用 `cron.list` 核对定时与开关。
- 哨兵用 `hooks.list` 核对开关，用 `hooks.disable` 停用，用 `hooks.enable` 启用。
