# 分段 Prompt 模板

> 复制以下结构，按占位符替换。`<图片1>` 为身份锚点；若本段有第二身份图或接续帧，按职责标注。模板默认无口播、硬切、纯色浅背景、正面平视中近景。

## 1. 输入资产定位与 0 秒基准

`<图片1>` 是本段出镜者的唯一身份锚点与唯一人脸依据：【年龄段、脸型、眉眼、鼻唇、肤色、发型、年龄感】。本段所有镜头都必须是这同一张面孔，不换成其他人、不变成旧参考人物。`<音频1>` 仅作配乐节奏与氛围参考：采用其【轻快美容流行乐】的节拍密度与氛围，不克隆歌词、不生成任何人声演唱或念白，不作成片固定音轨。镜头顺序、机位景别、手法动作、示意图形、字幕排版与切换节奏全部以第三部分文字为准。

0 秒基准：【素面/妆后状态】，胸部以上中近景，正视镜头，【背景描述】，【初始手势与图形状态】。

## 2. 参考主体绑定与生成目标

复刻参考片【前段/后段，对应时间区间】：【先引出问题/演示手法/展示效果】。全程固定机位、平视正面中近景，【仅在用户要求时注明自然侧脸】，机位不移动。

出镜者为 `<图片1>` 锁定的同一人：【五官、肤色、发型基础】。素面阶段：【低束发、近乎裸妆、表情平静】；精致阶段：【披发、清透妆容、唇色、眼神与表情】。服装：【上衣、内搭、美甲】。

面部受光充足、明亮均匀，正面柔光，眼下与脸颊无明显暗沉阴影；【背景颜色】。

示意图形：【白色虚线箭头、虚线多边形、红点标记、半透明轮廓线】，均为画面叠加示意，不遮挡五官。【按用户要求写明：全程不出现面霜、精华等护肤品膏体，不在皮肤上涂抹任何膏体，脸上没有白色或米色膏体痕迹。】

全程无口播、无讲解；背景音乐为【风格】，手法落点贴合节拍；仅保留轻微手部接触面部的真实拟音。

## 3. 逐时间段动作、声音与脚本

本段局部时间【开始】–【结束】秒，按顺序无空档覆盖，每个手法镜头约【1.5–2】秒，按节拍硬切。

- 【开始】–【结束】秒：【状态】正面中近景，【手势与动作】；画面中下部【颜色】文字“【字幕原文】”。
- 【继续按镜头补全；每个动作只写可执行的手势、方向、构图和文字。】

声音时间轴：【开始】–【结束】秒为【配乐氛围】，无任何人声、无歌词演唱；每个手法切换落在音乐节拍点上；手部接触面部时保留轻微真实触肤声，不额外加电子提示音。

## 4. 转场与尾态收束

段内全部为按节拍的硬切，不使用叠化、黑场或缩放转场。结束在【手势、构图、轮廓线、文字状态】；该状态供后段【物理接续/叙事接续】，不追加片尾定格、Logo 或 CTA。

## 5. 全片一致性与禁区

本段所有镜头必须是 `<图片1>` 同一人，脸型五官一致；素面与精致状态仅发型、妆容状态不同，不换脸。服装、美甲、背景、光线全程一致。出镜者必须是 `<图片1>` 这张虚构面孔，不得生成其他陌生或相似的现成人物脸。不新增口播、对白、旁白；不出现品牌、Logo、产品名、资质或功效承诺字幕；不把示意图形画成真实器械；【按用户要求写明膏体禁区】。
