# 换人失败诊断与修正

## 目录

- 1. 常见失败现象
- 2. 原因判断
- 3. 修正路径
- 4. 禁止事项

## 1. 常见失败现象

- 成片人物与参考片原人物五官高度雷同，像没有换脸。
- 前段是新人物，后段又变回旧人物。
- 身份图中的脸型、眉眼、年龄感没有进入视频。
- 前后段像两个陌生人，服装或发型断裂。
- 画面多出护肤品膏体、涂抹动作或产品包装。

## 2. 原因判断

### 参考视频强锚定人脸

参考视频不只是动作参考，模型会逐帧沿用其中的人脸、发型和表情。即使 Prompt 写“换成新人物”，强视觉参考仍可能覆盖文字约束。

判断方式：

- 对比成片首帧与参考片对应帧，脸型、眉眼、鼻唇、发束高度雷同。
- 已传入身份图，但视频画面仍与参考片面孔更接近。

### 身份图职责不明确

Prompt 没有写明身份图是唯一人脸依据，或同时让视频、尾帧、描述争夺面孔，模型会选择最稳定的参考来源。

### 错误尾帧带入后段

前段尾帧如果面孔错误，后段传入该尾帧后会继续沿用错误面孔；尾帧本应只承接手势和构图。

### 状态对比被误写成换人

素面与妆后是同一人的状态变化；如果把妆前、妆后拆成两张互不相关的脸，就会出现身份断裂。若用户明确要求前后不同年龄感，才使用分段身份图。

## 3. 修正路径

### 路径 A：保留视频参考但收窄职责

先尝试：

- 增加独立身份图作为唯一人脸锚点。
- Prompt 明确：长相只认身份图；视频只参考动作、机位、景别、图形、字幕排版和节奏。
- 禁止复刻参考片五官、发型高度和妆容细节。

若生成后仍像原片，说明视频参考无法被文字约束剥离，进入路径 B。

### 路径 B：彻底移除参考视频

- 不传参考视频，只传身份图；动作、机位、图形、字幕和节奏全部由文字 Prompt 承载。
- 音频可保留为节奏氛围参考，但不能带歌词或人声身份。
- 分段生成后核对每段面孔是否与身份图一致。

### 路径 C：后段不传错误尾帧

- 删除后段尾帧图片输入。
- 用文字写清 0 秒手势、手掌位置、构图、轮廓线状态。
- 后段面孔只认该段身份图。

### 路径 D：修正状态身份

- 同一人物的素面/妆后只改变发型、妆容、唇色、光线和表情。
- 每段重复绑定同一张身份图。
- 若前后确实需要不同年龄感，分别建身份图，并在母版中记录这是用户要求的对比结构。

## 4. 禁止事项

- 不要把参考片原人物作为“相似替代”保留。
- 不要靠叠化、黑场或缩放掩盖面孔漂移。
- 不要在未核对身份图覆盖情况时反复重生成同一路径。
- 不要为了换人新增口播、旁白、品牌故事或产品功效承诺。
- 旧版本留档不覆盖；修正版本另存版本号。
