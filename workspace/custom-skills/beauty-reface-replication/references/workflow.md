# 复刻拆解与分段工作流

## 目录

- 1. 元数据探测
- 2. 镜头拆解清单
- 3. 分段与接续
- 4. 生成前锁定项
- 5. 成片质检项

## 1. 元数据探测

生成前先确认参考片真实规格，不凭猜：

- 封装、编码、分辨率、比例、帧率、时长、码率。
- 音轨编码、声道、采样率、是否有真人旁白。
- 成片默认沿用参考片比例；时长超过当前模型单段上限时再分段。

若音轨无法判断是否有人声，用 ASR 或音频分析确认；背景歌曲歌词不等于口播旁白。

## 2. 镜头拆解清单

逐镜头记录以下字段：

| 字段 | 记录要求 |
|---|---|
| 时间区间 | 起止秒数，精确到 0.1 秒；段内动作不空档。 |
| 场景环境 | 背景颜色、空间、布光、阴影、画面简洁度。 |
| 人物状态 | 年龄段、脸型、发型、服装、美甲、表情、视线、姿势。 |
| 手法动作 | 手的位置、移动方向、接触部位、手势顺序；记录是否有膏体涂抹。 |
| 镜头语言 | 固定/运动机位、景别、角度、正面/侧脸、对焦与构图。 |
| 画面文字 | 原文、出现区间、颜色、位置、字号层级；文字不可错改。 |
| 示意图形 | 箭头、虚线轮廓、标记点、面罩线、动画变化；记录是否遮挡五官。 |
| 转场节奏 | 硬切、叠化、黑场、缩放；切点是否落在音乐节拍。 |
| 声音 | 配乐风格、节拍密度、人声/念白、触肤拟音。 |

## 3. 分段与接续

### 分段原则

- 按动作自然边界切分：问题引入、手法步骤、效果展示。
- 每段落在短语结束、动作完成或结果看清处；不在手势中途切断。
- 分段后仍属于同一条成片，每段复用同一身份设定，不另起故事。

### 接缝类型

- **物理接续**：同一连续时刻，保护身份、服装、位置、手势、握持和动作相位；可传入前段真实尾帧。
- **叙事接续**：换状态或时间省略，可改变发型、妆容与光线，但身份与因果不能重置。

### 尾帧使用限制

- 尾帧只能承接手势、构图和状态；不能作为后段人脸锚点。
- 若尾帧面孔仍是旧人物或错误年龄感，不传尾帧，改用文字描述起始手势、构图和轮廓位置。
- 后段身份图优先于任何尾帧人脸。

## 4. 生成前锁定项

在确认生成前写清楚：

- 模型、比例、总时长、各段秒数、成片数量。
- 每段身份图职责：唯一人脸依据；冲突时从身份图。
- 素面/妆前与精致/妆后的状态差异，以及哪些外观必须前后一致。
- 参考素材职责：视频只参考动作/机位/图形/排版/节奏；图片锁身份；音频只参考节奏氛围。
- 禁区：无口播、无品牌、无 Logo、无产品名、无资质承诺；按用户要求禁止膏体。
- 交付物：用户只要成片时，中间片段只留档不交付。

## 5. 成片质检项

拼接前核对：

- 两段分辨率、帧率、编码和画幅一致。
- 面孔来自身份图，没有沿用参考片原人物五官。
- 手势顺序、字幕原文、图形位置和节奏与复刻母版一致。
- 素面/妆后状态差异合理，身份没有漂移。
- 无多余膏体、品牌、Logo、旁白或用户未要求的元素。
- 成片可正常播放，时长与目标分段总和一致。

质检只核对已定要求，不主动扩展重生成；用户明确提出问题后再按新版本处理。
