# 美容手法换人复刻视频

## 适用判断

当用户提供一条参考短视频，并要求在不改变题材、场景、动作过程和节奏的前提下更换出镜人物时，按本 Skill 执行。

- 保留：场景与背景、布光、机位、景别、人物手势、手法顺序、画面文字、示意图形、硬切节奏、配乐氛围、前后状态对比。
- 更换：新虚构人物的脸、年龄感、发型和妆面状态；不复刻参考片原人物五官。
- 不适用：全新策划剧情、商品广告脚本、真实人物肖像克隆、需要保留参考片台词或口播配音的任务。

## 核心原则

1. **参考视频只能提供动作与结构参考，不能作为人脸身份锚点。** 只要把参考视频直接传入生成工具，模型通常会沿用其中原人物五官；仅靠 Prompt 写“换人”很难抵消视频面部锚定。
2. **新人物必须用独立身份图锁定。** 先生成或准备一张明确的新面孔作为唯一人脸依据；冲突时以身份图为准。
3. **前后对比不等于换两个人。** 素面/妆前与精致/妆后状态应保持同一身份的发型、妆容、光线变化；若用户明确要求前后使用不同年龄感，按分段身份图分别锁定，并在成片中说明这是对比结构。
4. **先拆片再分段生成，最后硬切拼接。** 单段生成超过模型时长上限时，按动作自然边界分段；接缝只保留手势、构图和状态，不把错误面孔带入后段。

## 工作流程

### 1. 读取并拆解参考片

- 探测参考片元数据：时长、比例、帧率、音轨、有无真人旁白。
- 逐镜头记录：时间区间、背景、人物动作、手势、景别角度、画面文字与颜色、示意图形、转场、音乐节拍。
- 识别信息结构：问题引入 → 手法步骤 → 效果展示；记录每一步对应的动作和字幕。
- 判断声音：无口播时由画面动作、文字和背景音乐承担信息；不要新增旁白。

详细拆解项见 [references/workflow.md](references/workflow.md)。

### 2. 建立复刻母版

在生成前固定以下内容：

- 成片比例、总时长、分段数与各段秒数。
- 新人物身份：性别、年龄段、脸型、肤色、发型、服装、美甲等；正面平视、双肩正对、不侧身，除非用户明确要求侧脸。
- 素面/妆前状态与精致/妆后状态的差异：发型、妆容、唇色、光线、表情。
- 保留文字的原文、出现区间、位置和颜色；不改写参考片画面文字。
- 禁区：不出现品牌、Logo、产品名、资质、量化功效承诺；按用户要求决定是否出现护肤品膏体或涂抹动作。

### 3. 准备身份图与分段素材

- 为每个需要独立身份的分段准备一张清晰正脸身份图；身份图是该段唯一人脸依据。
- 若参考片动作复杂，可先读取参考片动作，但生成时优先按 [assets/prompt-template.md](assets/prompt-template.md) 的纯文字动作描述承载流程；是否传参考视频必须先评估人脸漂移风险。
- 音频只作节奏氛围参考；不克隆歌词、不生成真人演唱或念白。核对输入素材时长上限。

### 4. 分段生成

- 每段 Prompt 必须写清：身份图职责、0 秒基准、逐时间段动作、字幕、图形、光线、声音、尾态和禁区。
- 后段若承接前段手势与构图，只在需要物理接续时传入前段真实尾帧；若尾帧面孔错误，不传尾帧，改用文字描述手势状态。
- 生成后核对：面孔是否来自身份图、动作是否承接、字幕是否在位、有无膏体或多余产品元素。
- 单个成片任务的生成/编辑次数与模型限制以当前宿主工具 schema 为准；不要自行升级模型或延长时长。

### 5. 拼接与交付

- 两段规格一致后按硬切拼接；不使用叠化、黑场、缩放等额外转场，除非参考片原本有明确转场。
- 核对成片时长、分辨率、帧率、音轨后交付。
- 用户只要成片时，不交付分镜表、Prompt 草稿或中间片段说明；中间片段只在制作记录中留档。

## 已知踩坑点

- **视频参考导致脸没换掉**：参考视频中的人脸会被强锚定；若身份图盖不住，移除参考视频，改用文字 Prompt 描述动作、机位、图形和节奏。
- **尾帧带错脸**：前段尾帧若仍是旧面孔，后段不要传该尾帧；用文字描述起始手势和构图。
- **膏体误入画面**：用户要求去膏体时，Prompt 明确禁止面霜、精华等膏体及皮肤涂抹痕迹，只保留手势和虚线箭头示意。
- **前后身份漂移**：每段重复写明身份图锁定的五官、发型、服装；妆前妆后只改变状态，不换身份。
