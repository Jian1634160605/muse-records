# 爆款模板快速复刻（ffmpeg 适配版）

目标只有一个：用用户提供的参考片和素材，尽快做出高相似度、可播放的 MP4 成片，并附带剪映字幕时间轴与工程说明，方便员工在剪映里做精修接力。默认直接执行，不先写长方案、蓝图或分析报告。

**与原版的区别**：原版在 ChatCut 里组装、返回"工程链接"；本环境没有 ChatCut，"组装"一步由 ffmpeg 管线实现，交付物是成片 MP4 + 可复刻的剪辑说明（已验证可用：马来西亚 42 岁案例 v1/v2 均按此流程对标 #1 爆款的镜头顺序与切点剪出）。

## 需要的输入

- 参考视频（爆款片）；
- 替换素材（照片/视频片段）；
- 是否需要成片。未说明时默认导出 1080p、时间线帧率、H.264 MP4；
- 音乐：只有用户直接提供音频文件或明确确认版权归属，才使用参考片同款/同类音乐，否则用无声版交付并在说明里标注。

素材没有命名时，按画面内容、角度和时长自动匹配。只有多个候选会改变故事含义或医疗阶段时才询问。

## 快速流程

### 1. 只分析剪辑必需信息

一次检查参考片，提取：

- 画幅、总时长、帧率；
- 主要镜头和切点（精确到帧，记录每个镜头起止时间）；
- 分屏或全屏布局；
- 标题、标签的文字、位置和大小；
- 音乐起点、主要重拍和基础转场/缩放点。

先看 8–12 个均匀采样帧，再只对明显切点查看相邻帧。不要逐帧扫描整条视频，不生成 JSON 蓝图，不转录与剪辑无关的对白。

### 2. 直接映射素材

按"画面作用 > 角度与构图 > 时长 > 清晰度"选择素材。优先保持参考片的镜头顺序和节奏；素材不完全对应时使用最接近的镜头继续完成，不因装饰性差异停工。

**医美红线**：映射绝不能改变医疗事实——术前/术中/术后/随访的时间线必须与素材真实拍摄状态一致，严禁把术后当术前、或用 AI/其他患者素材伪装随访效果。素材库中标记"不能发/不可发"的案例一律不用；要求眼部打码的案例必须先打码再进时间线。

### 3. 用 ffmpeg 组装

按以下顺序完成：

1. 建立主画面和精确切点（ffmpeg 剪切/拼接，照片用 Ken Burns 动态化，转场用基础淡入淡出或硬切）；
2. 已授权的音乐从第 0 帧对齐（无授权则交付无声版）；
3. 按参考片的文字层级添加字幕/阶段标签（生成 .srt/.ass 字幕文件与剪映字幕时间轴）；
4. 参考片中明显的基础转场或缩放用等效效果还原；
5. 静音不需要的原素材声音。

花字样式、精细转场、音乐卡点对齐等 ffmpeg 难以精细还原的部分，做基础版并继续，不为此停工——精修由员工在剪映里接力。

### 4. 异常才诊断

不要预先检查所有素材的编码和色彩。只有出现偏色、方向错误、无法预览或导出失败时，才检查对应素材。

HDR/HLG/PQ 素材进入 SDR 工程并出现异常时，制作 BT.709 派生文件后原位替换；保留原素材，不改其他轨道。

### 5. 最小验收

完成后只做：

- 一次整条时间线总览；
- 每个主要切点的前一帧、当前帧和后一帧；
- 检查黑帧、空隙、方向、标签遮挡、音乐同步和意外原声。

发现问题立即修正，最多两轮。除非用户要求精修，不进行全片逐帧审计或长篇相似度报告。

### 6. 交付

默认交付：

1. **成片 MP4**（1080x1920 竖屏、H.264），附下载链接；
2. **剪映字幕时间轴**（每条字幕的起止时间+文字，供员工直接导入剪映）；
3. **几句话说明**：已匹配的镜头、卡点、标签，以及仍存在的明显差异和未授权的音乐。

工作目录约定：`~/workspace/viral-video-ops/`，成片放 `assets/`，字幕与工程说明放同目录的 `.md`。

## 停止条件

仅在以下情况暂停并询问：缺少参考片、缺少决定故事的关键素材、音乐授权不明确、素材映射会改变医疗事实、导出在支持的重试后仍失败。其他小差异继续完成并在交付时简短标记。

## 成功标准

参考片的镜头顺序、主要切点、构图逻辑、标签层级和音乐节奏能被明显识别；时间线无明显错误；按用户要求得到 MP4 成片 + 剪映接力材料。不要承诺一定获得平台流量。
