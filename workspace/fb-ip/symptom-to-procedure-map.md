# 客户症状 → 手术项目对照表（2026-11-18 查证，用户亲授方法论）

用户原话：客户说脸部松弛、脖子松弛、皮松弛，这些都属于拉皮。Muse 要自己查为什么他们做拉皮，客户沟通时说什么，就能分析出他到底要做什么手术。

> 这张表是“初步判断”不是诊断。最终项目以医生面诊为准。私信里只按客户原话接、不下诊断、不承诺效果、不报价。

## 拉皮 Facelift（面部提升）—— 主线

客户常说的话：
- “脸松了 / 脸垮了 / 脸往下掉”
- “下颌线没了 / 下巴轮廓糊了”
- “脖子松了 / 脖子皱 / 火鸡脖子 / 双下巴”
- “法令纹深了 / 嘴角纹往下掉（木偶纹）”
- “看起来很累 / 显老，但我感觉自己还年轻”
- “护肤品、打针都没用了”

对应解剖问题：皮肤弹性流失、脂肪下移、SMAS 筋膜层松弛下垂 → 下颌缘出现赘肉（jowls）、鼻唇沟加深、嘴角下垂纹、颈部松弛。

为什么做：不是虚荣，是“看起来比实际感觉老/累”那个落差。拉皮是把深层组织复位、去掉多余皮肤，不是单纯把皮拉紧。

注意：拉皮管中下面部 + 脖子（常和颈部提升一起做），不管上半张脸。

## 眼睑手术 Blepharoplasty（上睑/下睑）—— 别误判成拉皮

客户常说的话：
- “眼睛没精神 / 看起来总很累 / 眼皮耷拉”
- “上眼皮遮住睫毛 / 眼皮厚重”
- “眼袋 / 眼下凹陷 / 泪沟”

对应：上眼皮皮肤多余下垂 → 上睑手术；眼袋、泪沟 → 下睑手术。眉毛下垂压着眼皮的 → 提眉，不是拉皮。

**关键区分**：客户说“眼睛累/眼皮松”不要直接归到拉皮，那是眼睑或提眉的地盘。Lauren Murphy 就是上睑翻修，不是拉皮。

## 鼻子 Rhinoplasty（鼻综合）—— 另一条主线

客户常说的话：
- “鼻子不够挺 / 鼻头大 / 鼻翼宽 / 鼻梁低”
- “想换个鼻型 / 鼻子跟脸不配”

对应：鼻梁、鼻头、鼻翼、鼻小柱的形态问题。跟松弛无关，别跟拉皮混。

## 颈部提升 Neck Lift—— 常和拉皮一起做

客户常说的话：
- “脖子松 / 颈纹 / 脖子上有竖条（颈阔肌带）”
- “下巴下面一坨 / 脖子比脸显老”

对应：颈部皮肤松弛、颈阔肌分离成带、颏下脂肪堆积。很多时候拉皮 + 颈部提升一起做，但脖子问题集中在下颌线以下时，颈部提升是主角。

## 速查

| 客户说 | 大概率方向 | 别搞错 |
|---|---|---|
| 脸松、垮、下颌线没了、法令纹深、嘴角下垂 | 拉皮 | 不是眼睑 |
| 脖子松、颈纹、火鸡脖、双下巴 | 拉皮 + 颈部提升 | 脖子单独明显时颈部提升为主 |
| 眼皮耷拉、总显累、眼皮遮睫毛 | 上睑手术 / 提眉 | 不是拉皮 |
| 眼袋、泪沟 | 下睑手术 | 不是拉皮 |
| 鼻型问题 | 鼻综合 | 跟松弛无关 |
| 额头纹、眉毛下垂 | 提眉 | 拉皮不管上半张脸 |
