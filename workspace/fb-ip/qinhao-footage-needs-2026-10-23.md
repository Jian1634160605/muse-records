## 收片优先级（今晚排序）

### P0 口播分段拍（最容易，先干这个）
对标：T07 医生科普型（钩子=高频顾虑/反常识 → 医生解释 → 证据 → 建议/CTA）。
- **恢复期真相**：术后第 3 天到底什么样、肿多久、什么时候能见人（正面回应"不回避恢复期"爆款因子）
- **深平面和普通拉皮的区别**：一句话讲清，不展开学术
- **面诊必问 3 个问题**：医生视角，什么样的人不适合做
- **疤痕护理**：切口在哪、疤痕怎么淡、多久看不见
- **维持几年**：美国客户高频问题，正面答
- 拍法：竖屏 9:16、手机实拍、无美颜、一题一段分开拍（方便后期按钩子重组）；每段开头 2 秒先抛钩子再自我介绍（爆点前置）

### P1 完整时间线案例（最稀缺，对准你要的 916 过程型）
对标：916 过程片语法 = 面诊划线 → 手术 → DAY3 → DAY10 → DAY30 → 前后对比；李峰 70 秒长叙事 = 抵达→面诊→检查→紧张→手术→苏醒→查房→照镜子高潮→6 个月终极对比。
- **同一患者**的：术前正面/侧面（同角度同光线）→ 面诊划线特写 → 术中关键步骤（避开血腥，拍无菌巾/缝合手/监护仪氛围）→ 术后包扎 → Day 3 / Day 7 / Day 14 / Day 30 同角度记录（**肿胀期也要，真实才有信任**）→ 照镜子反应 → 最终对比
- 红线：前后必须是同一个人、同角度（假对比我们直接弃用，这是死线）；不伪造时间线、不修真实患者医疗影像
- 能收齐 1 个完整案例，顶十条残片

### P2 面诊划线片段
对标：T09 面诊设计型（术前问题 → 面诊判断 → 分区设计 → 治疗/结果）。
- 医生在患者面部画线、讲解"这里为什么松、方案怎么定"的实拍片段（患者需知情同意，隐私按发布标准打码）
- 这是"面诊与方案可视化"爆款因子（出现 127 次），也是建立专业信任最快的一镜

### P3 患者访谈原声
对标：Nayak 患者访谈型（真实恢复细节 + 医患互动，拆成 60 秒单一问题）。
- 复诊时随手录：恢复期最难受的是哪几天、现在照镜子什么感觉、会不会推荐朋友来
- 保留患者原声，不摆拍背稿；情绪真实 > 话术漂亮

### P4 工作场景 / 查房 / 医院空镜（信任背书）
- 查房、团队协作、手术室外景走廊（不涉密区域）、多院区元素（重庆/上海/台湾——聊规模时要用的视觉证据）
- 用途：片头片尾氛围、主页装修、"集团实力"类内容的底料

## 拍摄硬规（今晚交代给拍摄的人）
1. 全部竖屏 9:16，手机实拍质感：自然皮肤、轻微手持感，**不美颜**
2. 每镜分段拍、单镜头时长留足（后期按钩子重组，不靠一次拍顺）
3. 真实影像三条死线：不伪造疗效时间线、不修真实患者照片、不拿别人的患者挂秦浩名
4. 文案与口播：不报价（价格零报价）、不承诺效果、不诊断——费用/方案一律"看个人情况，咨询团队对接"

## v2 增补（2026-10-23 晚，情报台 2026-10-22 榜单实证）

### 1. 榜首公式：15 秒对比短片（当日第 1 名，451 万播放 / 5.5 万赞 / 2520 评论）
结构（15 秒 7 镜）：故事型年龄钩子开场（画线患者近景 + 一句"她说她年轻时……"式字幕）→ 戴手套的手按压脸颊/下颌做检查（方案设计感）→ 患者年轻时旧照做锚点 → 同角度术前基线 → 术后同角度揭示 → 前后对比小窗收尾（术后大图 + 术前小窗，正、侧各一）。
**对收片的新要求**：
- P1 案例必须补收 **患者年轻时旧照 1–2 张**（拍翻拍/扫描件即可），这是钩子的一部分，不只是装饰
- 术前/术后必须 **成对同角度拍（正 + 侧）**，后期才能拼小窗对比；角度对不上整条作废
- 医生不必正脸出镜，**手部检查镜**就够——拍摄门槛低，面诊时顺手就拍
- 字幕全片统一一个高对比风格（黄底黑字类烧录字幕），最后对比镜不加字幕、让画面说话；结尾用提问式互动收（"你最先注意到哪处变化"类），不硬广

### 2. 连载恢复日记：别等拍完才发（当日第 3 名，19 秒，互动率 2.86% 为全榜最高档）
结构（19 秒 5 镜）：年龄明牌开场（红/黑底字幕直接标"59 岁"）→ 同一患者术前左、右侧面 → **术后第 7 天**多角度原样展示（淤青、泛红不遮）→ 结尾引导关注后续恢复。
**对收片的新要求**：
- P1 案例改 **连载制**：Day 7 就先发第一条，不等 Day 30 收齐；每个恢复节点发一条，结尾固定引导关注下一集
- 每个节点固定拍 **正 + 左 + 右三角度**、同光线同距离，方便跨期对比
- 开场镜头先拍一张"年龄明牌"画面（患者持牌/字幕位留空均可，后期加字）

### 3. 跨国患者旅程：我们的天然模板（模板库 T01，46 条样本；当日 Top 10 占 3 席）
当日第 5 名（49 秒第一人称旅程）：海外患者飞上海做深层提拉——抵达/酒店 → 面诊 → 术中 → 包扎恢复 → 乘车离院。这与我们"海外客户 + 主推上海总部"完全同构。
**对收片的新要求**：
- 有海外患者时按旅程线收全程，补拍三类镜头：**抵达（机场/酒店大堂）、城市空镜（上海地标/街景）、离院返程**
- 旅程片可长到 40–50 秒，是四类形式里唯一允许的长片；其余主力仍 15–25 秒
