## 推荐用法（给剪辑参考）

- 面诊/过程类（01、04、05 那种）：FRICTION（巴西 groove，有律动不吵）或 Tight（drift，稳）。
- 鼻子前后对比/揭晓类（02、06 那种）：REACTOR（高潮在后，适合揭晓）或 OVERCLOCK（鼓点密，卡点最顺）。
- 口播类（03 秦浩口播）：音乐音量压低一点，FRICTION 或 Tight 都行，别盖过人声——不过口播那条本身是秦浩原声，配乐只做底衬。
