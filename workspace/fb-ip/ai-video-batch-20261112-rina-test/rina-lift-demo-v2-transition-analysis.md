## 二、每个切点前后对照（锚点 = 切过去不跳的关键）

### 切点 1 — 3.73s（帧 112），宽→近
- 切前（3.70s）：BEFORE 宽景。脸偏素、哑光、略宽，头发束起；一只手放头顶、一只手掌水平托下巴；字幕「上提一提人有精神」。
- 切后（3.73s）：AFTER 近景。脸变精致、有光泽、略瘦，头发披下；双手框脸（一手竖在下巴前、一手在右脸颊拇指贴脸）；字幕同一句「上提一提人有精神」**不断、继续走**。
- 锚点：同一句字幕横跨切点；同一人、同一浅色背景、同一光线。脸在画面里的位置基本不变，只是景别推近 + 脸的状态切换。

### 切点 2 — 5.43s（帧 163），近→近
- 切前（5.40s）：AFTER 近景正脸，一手托下巴，脸颊有白色虚线弯箭头；字幕「上提一提人有精神」。
- 切后（5.43s）：头向她左侧微转约 30°（双眼仍全可见），第二只手突然出现在右脸颊、拇指贴脸；字幕换成「中间一顺显柔和」；箭头消失。
- 锚点：**下巴前的手一动不动、脸在画面里的位置和大小完全不变**。一帧之内只变三样：头角度、第二只手、字幕。这就是“顺”的来源——眼睛盯住的东西没动，变的都是新信息。

### 切点 3 — 7.07s（帧 212），近→近
- 切前（7.03s）：头微转约 30°，手贴脸颊，脸颊有白色弧形亮带；字幕「中间一顺显柔和」。
- 切后（7.07s）：头回正到约 10°，第二只手变成一根食指横指下颌线；字幕换成「下边收一收显利落」。
- 锚点：同切点 2——下巴前的手不动、脸位置大小不变；只变头角度、手势、字幕。

### 切点 4 — 8.67s（帧 260），近→宽
- 切前（8.63s）：AFTER 近景，头微转，手指在画面右缘、下颌有白色上提箭头；字幕「下边收一收显利落」。
- 切后（8.67s）：AFTER 宽景，脸在画面里变小、露出更多上身；双手重新框脸（一手放头顶、一手水平托下巴）；字幕换成「最后定一定显协调」。
- 锚点：同一人同一背景同一光线 + 字幕逻辑接续（提/顺/收/定四字收尾）。景别跳变是故意的：从细节回到整体，收束四个手法。

### 切点 5 — 10.27s（帧 308），宽→宽
- 切前（10.23s）：AFTER 宽景，脸部白色椭圆轮廓线，双手框脸；字幕「最后定一定显协调」。
- 切后（10.27s）：BEFORE 宽景——脸变回素颜哑光状态、头发束起；只剩一只手掌托下巴，头顶的手没了；无字幕。
- 锚点：**托下巴的手掌位置、脸位置、景别全都不变**，只变脸的状态。这是为下一个转场（溶解变脸）做的铺垫：先把脸“打回原形”，观众才看得出变化。

### 切点 6 — 约 11.0–11.4s（帧约 330–342），交叉溶解，全片唯一一次溶解
- 11.0s：纯 BEFORE 脸，眼睛看向她右侧，字幕「做完的效果很直观」开始淡入。
- 11.1s：重影帧——两张脸叠在一起（束发的 BEFORE 脸 + 披发的 AFTER 脸各半透明），托下巴的手掌基本保持清晰、位置不动。
- 11.3s：溶解完成，AFTER 脸，微笑、看镜头；字幕「做完的效果很直观」完全显现。
- 锚点：机位、景别、托下巴的手全程锁死不动，只有脸在原地“变”。溶解约 0.4 秒，不长不短。
- **这是全片“转场的精髓”**：前面所有硬切都是为了这一刻——脸在同一位置、同一只手托着、慢慢从“前”变成“后”，观众一眼看懂“做完的效果”。

### 切点 7 — 14.33s（帧 430），宽→宽
- 切前（14.3s）：AFTER 宽景，托下巴掌，右脸颊白色轮廓线；无字幕（“线条顺了”刚退场）。
- 切后（14.4s）：AFTER 宽景，示范者的黑指甲手消失，换成模特自己的双手在下巴下交叠（自然指甲、有戒指）；微笑；字幕「整张脸紧致饱满」淡入。
- 锚点：脸位置大小基本不变、同一人同一背景；收尾姿势一换，视频进入“展示结果”段落（14.33–16.9s：整张脸紧致饱满 → 精致又有弹性）。

## 三、为什么原片切过去感觉顺（五条规律）

1. **硬切为主，溶解只用一次**：7 个转场里 6 个是硬切（1 帧完成），只有 before→after 变脸那一下用约 0.4 秒溶解。硬切干净利落，溶解留给唯一需要“变”的瞬间——轻重分明。
2. **字幕不断、横跨切点**：切点基本都落在句子中间（3.73s 在「定」字里、5.43s 在「中间一顺」句中、7.07s 在「下边收一收」句中），字幕这条线从不断，观众的注意力被字幕拽着走，就顾不上画面跳了。
3. **每个切点都有锚点**：切点 2、3、5、6 的锚点是同一只不动的手（下巴前的手 / 托下巴掌）+ 脸在画面里的位置大小不变；切点 1、4、7 的锚点是同一人、同一背景、同一光线 + 字幕逻辑接续。眼睛有东西可抓，就不觉得跳。
4. **景别只在两个家族里跳**：近景家族（脸占满画面，3.73–8.67s）与宽景家族（露出上身，0–3.73s、8.67–16.9s）。同一家族内切，脸的大小不变；换家族时切，变化本身就是节奏（推近看细节、拉远收整体）。
5. **脸只有两个状态，且状态切换都有交代**：BEFORE（素、哑光、略宽、头发束起、中性表情）与 AFTER（精致、有光泽、略瘦、头发披下、微笑）。3.73s 硬切换状态（配字幕“上提”）、10.27s 硬切换回 BEFORE、11.0–11.4s 溶解变回 AFTER——三次切换，每次都有明确的视觉理由，绝不无故换脸。

## 四、v1 为什么没达到转场精髓（逐条对照）

1. **v1 全片用了 0.25 秒交叉淡化接段**：原片 6/7 是硬切，v1 却在每个接缝都淡化——每处都出轻微重影，整片发“飘”，没有一处是脆的。这是被否的直接原因。
2. **v1 的接缝位置全错**：v1 接在 5.0s / 7.0s / 8.25s，原片切在 3.73s / 5.43s / 7.07s / 8.67s / 10.27s / 11.0–11.4s / 14.33s。v1 在 5.0s 切断了「上提」句，在 7–8.5s 用了错误的正脸双手框脸姿态（原片此时是转头 + 手指点下颌线）。
3. **v1 没有 before/after 两个状态**：全片同一张“后”脸，10.27s 没有打回 BEFORE、11.0–11.4s 没有溶解变脸——“做完的效果很直观”这句最核心的 payoff 在 v1 里没有任何画面支撑。
4. **v1 段间脸的大小和肤质在变**：seg1 哑光痘印清晰、seg3 光滑发亮，段一接一段脸就换一张。原片同一家族内脸大小、肤质完全一致。
5. **v1 的手在接缝处跳变**：5.5s 右缘模糊手指入画、9s 托腮手糊化。原片每个切点都有一只手钉在原地不动当锚，v1 没有锚。
6. 其余已知缺陷（v1 自查文件已记）：seg1 约 2.2–4.3s 闭眼约 2 秒（原片全程睁眼）；16s 笑容偏大。

## 五、v2 重建规格（按此执行，不凭感觉）

**总时长 16.90s、1080x1920、30fps（与原片一致，帧号与上表一一对应）、h264 + AAC 单音轨；视频内无任何 AI 字样；音乐沿用原片音轨（ref-music.m4a，纯音乐无人声）。**

虚拟人：换一张新虚拟脸（不用原片那个人、不用秦浩脸、不用 Rina 脸、不用 v1 那张脸）；**同一虚拟人贯穿全片**；两个状态——BEFORE（素、哑光、脸略宽、头发束起、中性表情）与 AFTER（精致、有光泽、脸略瘦、头发披下、微笑）。所有片段用同一身份锁定（同一参考图/同一种子），段间肤质、脸型不得变。

生成策略（省额度、保一致）：B/C/D 三段可由**一条约 5 秒的 AFTER 近景连续镜头**切出（3.73–8.67s：起手双手框脸 → 头微转手贴脸颊 → 头回正指下颌线），ffmpeg 按帧硬切成三段；A、E、F（前/后两态）、G 各一条。共约 6 条生成。**F 前态与 F 后态必须是同一机位同一手位**，只变脸（溶解用）。

拼接铁律：
- 除 F 段内 11.0–11.4s 的溶解外，**其余全部接缝用 ffmpeg concat 硬切，禁用 xfade / 淡入淡出**；切点严格按上表帧号（±1 帧）。
- 每段切点两侧的锚点手必须对上：B/C/D 段交界处下巴前的手位置不变；E/F 交界处托下巴掌位置不变；F/G 交界处脸位置大小基本不变。
- 标注（箭头/亮带/椭圆）与字幕沿用 v1 的 make_overlays.py + rina-lift-subs.ass（字幕时间轴已按原片实测帧核对过，直接复用），但标注坐标必须按 v2 新人脸的实际位置重画、逐帧复核，不得照搬 v1 坐标。
- 开场 0–约 1.0s 做白场淡入（与原片一致）。

修掉 v1 全部已知缺陷：全程睁眼；前后肤质一致；手不糊、手指不变形（黑指甲油完整）；7–8.5s 必须是转头 + 手指点下颌线（不再用正脸双手框脸替代）；16s 笑容收住、微笑即可。

审核：E07 90 分门，最多返修 3 轮；重点审转场（切点帧号、锚点手、溶解只此一处、before/after 两态是否成立）。
